## 修复：start_mac.sh 在 set -u 下启动即崩
- 现象：`bash scripts/start_mac.sh` 报 `app_log\ufffd: unbound variable`，退出码 2，服务起不来。
- 根因：Bash 在 `set -u` 下对 `$var` 紧跟多字节 UTF-8 字符（全角括号 `（`，首字节 0xEF）会将其并进变量名，误判为未绑定。最小复现：`bash -c 'set -u; app_log=x; echo "$app_log（由"'` 同样报错。
- 修复：`scripts/start_mac.sh` 第 20、73 行的 `$arg`、`$app_log` 改为 `${arg}`、`${app_log}`，用花括号明确变量边界。
- 验证：脚本启动成功，/health、/ready、首页、19 个路由全部 200；8001 已停释放。
- 经验：本项目 shell 脚本普遍 `set -u`，echo 中文提示里 `$var` 后紧跟全角标点时必须用 `${var}`。已扫描 scripts/*.sh，仅 start_mac.sh 有此隐患，其余无。
